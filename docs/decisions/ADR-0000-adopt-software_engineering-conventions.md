# ADR-0000: Adopt Software Engineering conventions

**Status:** Proposed (accepted by merging this branch)

## Context

claimr is adopted by **Software Engineering**, governed by the
mastermind **mastermind**. Conventions are projected in —
everything lands as one reviewable change; nothing is
written silently.

## Decision

This repository follows Software Engineering's ways of working:
journaling, decision records, and implementation plans as
laid out in this change. Reflection (distilling changes
back into the mind) is opt-in and not yet enabled.

## Consequences

Drift between this repository and Software Engineering becomes visible
and reviewable instead of silent.
