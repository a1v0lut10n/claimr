# CLM-0008: The REPL

## Objective

An interactive loop for claimr per
[the REPL design record](../../design/2026-08-18-repl-interaction-model.md):
`claimr` (or `claimr -i file`) presents `?- `, answers queries stepped
Prolog-style (`;` next, Enter/`.` stop), accepts clauses at the prompt to
extend the session, offers `:` commands to load, list, clear and configure,
and can be interrupted with Ctrl-C. Batch mode (`claimr file`) is unchanged.

## Context

All four evaluator stages are done; answers are exact and simplified. What
is missing is the interactive experience: today every query in a file
prints all answers eagerly, and there is no way to add a fact and ask again
without editing a file. The design record fixes the interaction model
(Prolog stepping, GHCi-style commands, clauses at the prompt).

## Deliverables

1. **Evaluator hook** — `Solutions::with_interrupt(flag: Arc<AtomicBool>)`
   (or a setter): the machine checks the flag every N resolution steps and,
   when set, stops the search as if exhausted and reports
   `Solutions::interrupted() == true` (no error, no answer). Batch mode
   never sets it. `Program` gains what the REPL needs to build a session
   incrementally without re-parsing: `Program::compile` already takes
   clauses; the REPL keeps the session's `Vec<Clause>` (with origin: file
   or prompt) and recompiles on change (programs are small; keep it
   simple, note it as a later optimisation).
2. **`src/repl.rs`** — the loop:
   - reading: `rustyline` editor with in-memory history when stdin is a
     TTY; plain line reading otherwise (piped stdin); multi-line input
     until a terminating `.` outside a comment; `?-` prefix optional for
     queries; blank lines / comments ignored;
   - dispatch: `:command args` lines → commands; otherwise parse with
     `parse_program_spanned` (positions relative to the typed input): a
     `Query` runs, any other clause is appended to the session (constraint
     facts validated by recompiling; a rejected clause is reported and not
     added);
   - answering: stepping by default — print answer, then if the search may
     continue print ` ;`-style prompt and read a key/line: `;`/`n` → next,
     Enter/`.`/`q` → stop; `false.` when none; `:all` mode prints all
     answers (respecting `:limit`); runtime errors as in batch;
   - commands: `:load file`, `:reload`, `:list`, `:clear`, `:limit N`,
     `:all` (toggle), `:help`, `:quit`; unknown command → one-line help;
   - Ctrl-C: `ctrlc` handler sets the interrupt flag; a running query
     stops with `interrupted.`; at the prompt the line is discarded;
   - exit: `:quit`, Ctrl-D (EOF) → exit code 0.
3. **CLI** (`src/main.rs`): `claimr` with no path → REPL; `-i` /
   `--interactive file` → run the file (as batch, printing its queries'
   answers) then REPL with that session; `--help` documents all flags;
   `--limit` applies to batch and seeds the REPL's `:limit`.
4. **Tests** (`tests/repl.rs`, driving the binary through pipes):
   stepping (`;`, Enter, `.`), `false.`, `:all` and `:limit`, clauses at
   the prompt (fact, rule, constraint fact; a rejected unsatisfiable
   constraint fact), `:load` of an example and its answers, `:list`
   round-trip (listed text re-parses to the same clauses), `:reload` and
   `:clear`, syntax error position on prompt input, runtime error, `-i`
   mode, EOF exit, unknown command; unit tests for the input accumulator
   (terminating `.` inside `%` comments, `1.5` vs `1.`, multi-line);
   an interrupt test through the library hook (a `nat` query with the flag
   set from another thread stops). Clippy clean.
5. **Docs** — every path in `affects`: `docs/architecture/README.md` `cli`
   row; `components/evaluator.md` (interrupt hook); `README.md` (Usage:
   REPL session transcript, commands table); `CLAUDE.md` (commands: how to
   start the REPL, testing through pipes).

## Explicitly out of scope

- `:save`, persistent history, syntax highlighting/completion, a
  language-server; changing batch-mode output; grammar changes (commands
  are not claimr syntax); performance of session recompilation.
