# Catalyst

Stage 2 of the idea pipeline: ideas from [`../incubation/`](../incubation/)
that are being actively fed — evidence gathered, shape sketched, connections
to other work drawn — but not yet committed to a design. Still no ticket.

Entries leave here by graduating into a design record (`../design/`) and/or
a task (`../tasks/`) with a claimed `CLM` ticket, or by being dropped back
to incubation. Same file format as incubation: `YYYY-MM-DD-short-slug.md`.
