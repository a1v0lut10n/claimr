# Incubation

The earliest slot in the idea pipeline: raw concepts worth remembering,
captured the moment they occur — a paragraph or a page, no commitment, no
ticket. Entries here have **no status field and no schedule**; they're allowed
to be wrong, vague, or dormant for months.

Pipeline: **incubation → catalyst → design → tasks/implementation**.

- An idea graduates to [`../catalyst/`](../catalyst/) when someone starts
  actively feeding it (evidence, shape, connections) — still before any
  design commitment.
- From catalyst it becomes a design record (`../design/`) and/or a task with a
  claimed `CLM` ticket (`../tasks/`).
- Graduation is a `git mv` plus whatever rewriting the maturation earned; the
  history stays.

File format: `YYYY-MM-DD-short-slug.md`, a title, and prose. Nothing else is
required. `/aivolution:incubate <idea>` captures a new entry on demand.
